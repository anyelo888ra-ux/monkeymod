# 🐵 monkeymod

¡Bienvenidos a **monkeymod**! Este proyecto es mi propia versión personalizada del entorno de programación por bloques inspirado en Scratch, desarrollado utilizando **HTML, CSS y JavaScript puros**.

## 🚀 Características
*   **100% Estático:** Se ejecuta directamente en el navegador a través de GitHub Pages, sin necesidad de servidores pesados.
*   **Interfaz Ligera:** Una UI personalizada, minimalista y diseñada desde cero, dejando de lado estructuras complejas para lograr la máxima velocidad de carga.
*   **Código Abierto:** Basado en tecnologías libres y distribuido bajo la licencia MIT.

## 🛠️ Tecnologías utilizadas
*   **HTML5 & CSS3** para la estructura y el diseño visual de la interfaz.
*   **JavaScript** para el control lógico de la aplicación.
*   **Blockly / Scratch Engines** como motores base para la manipulación y el procesamiento de los bloques.
